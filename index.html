About the Web Site Theme and Editor

I decided to use Microsoft FrontPage '98 to design this Web site, as I have decided that I appreciate the late '90s Web site aesthetic. This theme is called "Nature", and I chose it because it reminds me of autumn. Perhaps I'll change it once the seasons change (winter, spring, summer), but there are only a select few other themes that I like as much as this one.

I chose to use a WYSIWYG editor because I didn't feel like sitting around to custom-design the site, and I know if I did that it would look the same as every other site (Bootstrap -- count your days), so I decided to use this program. However, I have three gripes:

The default encoding is ISO-8859-1 (Windows) which doesn't mix well with Web servers that serve UTF-8. I had to go through each file individually to fix the encoding.
The script editor is garbage. Once I insert a script, there's no going back to edit it (at least in the header).
I can't figure out how to edit the theme's layout to add a footer on every page; that's why the copyright and modified date are in the header.
